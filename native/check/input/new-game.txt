# Controller script of milestones M11 new-game and M14 outset-real (docs/NATIVE_PORT_PHASE4_6.md,
# step NG-probe; syntax in native/src/pc/harness/pc_input.cpp): <frame> <buttons> <stickX> <stickY>, each
# line holding until the next. Both milestones start from a clean memory card (run.sh puts it
# in the run directory). Every button is held two frames, so it triggers once.
# - Title (as file-select.txt): the first START makes d_a_title skip to "press START", the second
#   requests the name scene (about frame 760).
# - The card has no save file: the name scene asks whether to create one (about frame 780), with
#   No preselected. The stick left (frames 880-885) moves to Yes, A (900) creates the file, A
#   (1000) closes the "file created" message; the file select opens (about frame 1050).
# - File select: A (1100) picks file 1 (new), A (1200) confirms; name entry runs from about
#   frame 1230.
# - Name entry: A three times (1300-1340) enters "AAA", START (1380) moves the cursor to END, A
#   (1420) confirms. The name scene requests the OPEN scene (the prologue); M11 new-game is logged
#   60 frames after it executes (about frame 1525).
# - The prologue runs by itself (no input skips it on a new file) and ends at about frame 8020,
#   when the game changes to the PLAY scene at the save's return place (Outset, sea room 44).
# - Outset (M14 outset-real): from frame 8200, B taps every ten frames advance the intro event's
#   messages (as outset-control.txt, where the event lasts about 3,000 frames); B rather than A,
#   which would start a new talk with Aryll. Then the main stick is held in six directions, 140
#   frames each with a 20-frame rest. These frames are provisional: the PLAY scene has not yet
#   executed after the prologue (see the NG-probe log in docs/NATIVE_PORT_PLAN.md); the M14 boot
#   loop retimes them once it does.
