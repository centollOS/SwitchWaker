# Run options of the native port on the Switch. Copy to the SD card as
#   switch/centollos/native/env.txt
# (scripts/switch/push.sh --native-env switch/native/env.example.txt). One NAME=value per line,
# nothing else on it; a line starting with # is ignored. Without the file the Switch defaults
# apply:
#   COS_DISC=/switch/centollos/GZLE01.iso   (the disc image: push.sh --disc or --game)
#   COS_RUN_DIR=/switch/centollos/native    (where the harness writes backtrace.txt)
#   COS_PERF_EVERY=60                               (a "[cos] perf" line every 60 game frames)
#   COS_HITCH_MS=50                                 (a "[cos] hitch" line for a frame over 50 ms)
#   COS_STALL_S=90                                  (exit 11 after 90 s without a game frame)
#   COS_ASPECT=16:9                                 (widescreen; 4:3 is the GameCube picture)
# Any COS_* variable of native/README.md ("Running centollos (phase 6)") works here. Remove the # in
# front of one of these to use it:
#
# Exit 0 when the title's sea is reached (milestone M7, "opening"):
#COS_MILESTONE=opening
#
# Exit 0 after this many game frames:
#COS_FRAMES=1800
#
# Log every scene the game creates:
#COS_TRACE=scene
#
# Start-up check only: every static constructor ran and the 502 actor profiles are in place:
#COS_SMOKE=static-init
#
# Write through a null pointer, to check the crash report ("[cos] CRASH" in the log, then
# Atmosphère ends the app with its own report):
#COS_SMOKE=crash-test
#
# Do not start JAudio and the DSP (the game is silent either way for now):
#COS_AUDIO=off
#
# Dawn's GL queue: drain the GPU with glFinish after every submission, as builds before the GL fence
# queue did (to compare frame times; "glFinish" in the perf-switch line):
#COS_SWITCH_GL_FINISH=1
